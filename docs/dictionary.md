## データを追加するとき

1. 採用本文から抜粋を選び、版・改行・必要なルビ・注記の有無を確認する。傍点・注記を含む箇所は選ばない。詩の本文は `text: |2-` とし、YAML 構造のインデントを明示して先頭行の字下げも保持する。本文の字下げ 1 段は半角 2 スペースとする。
2. 作者のファイルの該当作品に、`quotes`・`places`・`beings`・`onomatopoeias` を追加する。
3. 小文字英数字をハイフンでつないだ ID を手動で付ける。公開後は表記や分類が変わっても維持する。
4. 同じ種別の ID は全作者で一意にする。詩・短歌・俳句・散文は全体で `quotes`、登場者の 3 分類は全体で `beings` として重複を検証する。
5. 同じ対象は一か所で定義し、別作品では `ref` を使う。`location` と `source_url` は出典関係ごとに記録する。
6. 発表年（不明なら刊行年）の順に置く。同年・年代不明は定義順を維持し、年代不明を最後に置く。作者ファイル間の同年順は `authors.yml` の定義順による。
7. 注意情報が必要なら `content_warnings` に説明文を書く。不要なら省略する。地名には記載しない。
8. RSpec を実行し、同梱辞書の件数・期待値も追加内容に合わせて更新する。テスト用の架空本文や `example.com` の出典を製品データに入れない。

読み込みは安全な YAML ロードを用い、オブジェクトタグ・YAML エイリアス・重複キーを許可しない。共有対象には YAML アンカーではなく `ref` を使う。
不明なキー、重複 ID、未解決参照、必須属性の不足、不正な種別・座標・詩の字下げも `Ihatov::DataError` で検出する。

### 省略値と型

| 項目 | ルール |
| --- | --- |
| 作者 | `id`・`family_name`・`given_name` 必須。`name` は半角スペース結合 |
| 作品 | `id`・`title`・`edition` 必須 |
| 採用版 | `url`・`bibliography` 必須。`aozora_id` は正の整数。青空文庫以外では省略時または `null` 指定時に `nil` |
| 年代 | `announced_year`・`published_year`。正の整数。省略時または `null` 指定時は `nil` |
| 収録配列 | 省略なら空配列。明示的な `null` は型エラー |
| 抜粋 | `id`・`kind`・`text` 必須。kind は poem/tanka/haiku/passage |
| 地名 | `id`・`name`・`real` 必須。座標は省略時または `null` 指定時に `nil` |
| 登場者 | `id`・`kind`・`name` 必須。kind は person/character/creature |
| 擬音語 | `id`・`text` 必須 |
| 出典関係 | `location` は省略時または `null` 指定時に `nil`。`source_url` は省略時または `null` 指定時に `edition.url` |
| 注意情報 | 説明文字列の配列。省略で空配列。地名では使用不可 |

`coordinates` は `latitude` と `longitude` を持つ数値のマッピング。WGS 84 の十進度で、山は山頂、地域・川は代表点を使う。緯度は−90〜90、経度は−180〜180。非実在の地名に座標を付けない。
