## 編集上の判断

- オシラサマは第69話に記される娘と馬に由来する神を指す項目として登録した。人間の姿をした単独の登場者や単なる木像としては扱わず、この辞書では `creature` とする。分類は編集上の判断であり、YAMLの `kind` で変更できる。今回は名称のみを収録し、第69話の動物への暴力などを含む本文は抜粋として追加していない。名称自体には注意情報を付けない。

- 『雪渡り』『やまなし』は新字新仮名の上記版に固定した。『雪渡り』の初出は1921年12月と1922年1月にまたがるため、先の1921年で並べる。『やまなし』は1923年の初出を登録した。
- 『春と修羅』の追加分もID 1058に統一した。文字化け・外字注記のある候補は推測で補わず、照合できる別の箇所を選んだ。「カーバイト倉庫」は冒頭5行のみ。他の追加7篇は本文を一まとまりとして収録し、詩題と末尾の制作日は含めない。
- 「不来方城」は短歌本文の「不来方のお城」に対応する地名として登録した。引用本文の表記は変更しない。
- 『遠野物語』第50・51話は一段落を維持する。猿の経立の出典は候補案の第44話ではなく、本文で確認した第46話。第46話の注記を含む本文は抜粋に採用していない。
- 追加抜粋には説明を要する差別表現・自傷・具体的な暴力描写を選んでいないため、注意情報を省略した。これは作品全体についての安全判定ではない。

- 『春と修羅』は本文を照合できた新字旧仮名のID 1058を初期実装で固定した。新字新仮名として登録されているID 457は外部アーカイブへのリンクであり、取得結果の文字化けにより今回の引用箇所を照合できなかった。**公開前に新仮名版の採用可能性を再確認する**。新仮名へ独自に書き換えたり、異なる版を混ぜたりしない。
- 『春と修羅』の段階的な字下げは、原文の全角空白1文字を1段として半角2スペースへ変換した。`ZYPRESSEN 春のいちれつ`の本文中の空白は保持した。
- 『一握の砂』は旧仮名の表記を維持する。仮名遣いそのものを警告対象にしない。「大という字」の一首に、自死への言及について注意説明を付した。
- 『風の又三郎』の擬音は全角スペースを半角にする。散文抜粋内の同じ擬音にも同じ整形を施した。歌4行は `kaze-no-matasaburo-opening`、学校の描写2段落は `kaze-no-matasaburo-school` として独立させる。
- 散文の段落頭の字下げは除去する。段落の改行と本文中の空白は保持し、詩の段階的な字下げはこの処理の対象にしない。
- 『遠野物語』第57話は一段落なので、3行にするための改行を加えない。「人ののように」は採用本文の表記どおり維持する。該当箇所の巻末校訂・更新状況は公開前に再照合する。
- 地名は本文の「カルボナード火山島」に統一する。固定IDは `carbonado-volcano` を維持する。
- 「河童」は本文の「川童」、「座敷童子」は「ザシキワラシ／座敷ワラシ」をまとめる呼称として登録した。これらの編集呼称を本文の逐語的引用と混同しない。
- 『春と修羅』の「イーハトヴ」と『グスコーブドリの伝記』の「イーハトーヴ」は同じ対象にまとめた。各作品の位置情報は別の`Source`として保持する。
- 作品自体の発表年・刊行年を、後年の底本の発行年で代用しない。今回は『春と修羅』1924年、『グスコーブドリの伝記』1932年、『一握の砂』『遠野物語』1910年を登録し、未確認分は未登録とした。
- 実在地名の座標は未登録。地名の`real`は座標の有無によらず指定する。

## データを追加するとき

1. 採用本文から抜粋を選び、版・改行・ルビ・注記の有無を確認する。傍点・注記を含む箇所は選ばない。詩の本文は `text: |2-` とし、YAML構造のインデントを明示して先頭行の字下げも保持する。本文の字下げ1段は半角2スペースとする。
2. 作者のファイルの該当作品に、`quotes`・`places`・`beings`・`onomatopoeias`を追加する。
3. 小文字英数字をハイフンでつないだIDを手動で付ける。公開後は表記や分類が変わっても維持する。
4. 同じ種別のIDは全作者で一意にする。詩・短歌・俳句・散文は全体で`quotes`、登場者の3分類は全体で`beings`として重複を検証する。
5. 同じ対象は一か所で定義し、別作品では`ref`を使う。`location`と`source_url`は出典関係ごとに記録する。
6. 発表年（不明なら刊行年）の順に置く。同年・年代不明は定義順を維持し、年代不明を最後に置く。作者ファイル間の同年順は`authors.yml`の定義順による。
7. 注意情報が必要なら`content_warnings`に説明文を書く。不要なら省略する。地名には記載しない。
8. RSpecを実行し、同梱辞書の件数・期待値も追加内容に合わせて更新する。テスト用の架空本文や`example.com`の出典を製品データに入れない。

読み込みは安全なYAMLロードを用い、オブジェクトタグ・YAMLエイリアス・重複キーを許可しない。共有対象にはYAMLアンカーではなく`ref`を使う。
不明なキー、重複ID、未解決参照、必須属性の不足、不正な種別・座標・詩の字下げも`Ihatov::DataError`で検出する。

### 省略値と型

| 項目 | ルール |
| --- | --- |
| 作者 | `id`・`family_name`・`given_name`必須。`name`は半角スペース結合 |
| 作品 | `id`・`title`・`edition`必須 |
| 採用版 | `aozora_id`（正の整数）・`url`・`bibliography`必須 |
| 年代 | `announced_year`・`published_year`。正の整数、省略・nullはnil |
| 収録配列 | 省略なら空配列。明示的なnullは型エラー |
| 抜粋 | `id`・`kind`・`text`必須。kindはpoem/tanka/haiku/passage |
| 地名 | `id`・`name`・`real`必須。座標は省略またはnullでnil |
| 登場者 | `id`・`kind`・`name`必須。kindはperson/character/creature |
| 擬音語 | `id`・`text`必須 |
| 出典関係 | locationは省略・nullでnil。source_urlは省略・nullでedition.url |
| 注意情報 | 説明文字列の配列。省略で空配列。地名では使用不可 |

`coordinates`は`latitude`と`longitude`を持つ数値のマッピング。WGS 84の十進度で、山は山頂、地域・川は代表点を使う。緯度は−90〜90、経度は−180〜180。非実在の地名に座標を付けない。
